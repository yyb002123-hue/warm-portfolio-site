# 影像校友会 H5 上线方案说明

## 项目定位

本项目是一个轻量内容展示 H5，用于集中展示校友会每月活动、照片、文章和作品。访问对象主要是学员、校友和相关老师。

页面本身不属于复杂业务系统，主要压力来自图片访问和内容更新。

## 当前建议方案

第一阶段建议只上线“前台展示版”：

- 用户只能浏览内容
- 不提供线上后台入口
- 不提供公网在线编辑
- 不提供公网 Excel 上传
- 内容由维护人本地整理后，通过固定发布流程更新

这样可以先降低安全审查风险，让页面展示功能先跑起来。

## 为什么不建议第一阶段上线后台

后台一旦放到公网，就需要解决权限和安全问题：

- 谁可以登录
- 谁可以上传图片
- 谁可以修改内容
- 上传内容是否需要审核
- 操作记录是否可追溯
- 接口是否会被非授权人员调用

如果这些没有明确，技术部门通常不会允许直接上线。

## 内容更新方式

当前阶段采用“本地维护，前台发布”的方式：

1. 维护人在本地后台修改内容
2. 本地保存后生成公开展示数据
3. 上线前执行公开版检查
4. 只发布前台展示文件

这样普通用户看不到后台，也不能直接修改内容。

## 图片和资源预估

预计每月新增照片 100 张以内。图片压缩后，每张建议控制在 300KB-800KB。按这个规模，存储和访问压力不大，整体属于轻量展示项目。

真正需要持续投入的是内容维护流程，而不是服务器算力。

## 后续二期方向

如果后续需要多人在线维护，可以再升级为正式内容管理方案：

- 公司账号登录
- 后台权限控制
- OSS 图片上传
- Excel/飞书表格更新
- 操作日志
- 内容审核

二期需要公司技术资源正式评估和排期。

## 结论

建议第一阶段按“只展示、不开放编辑”的低风险方案上线。后台管理、Excel 上传和图片上传能力保留在本地或后续二期处理，等公司资源和权限方案明确后再接入正式后台。
